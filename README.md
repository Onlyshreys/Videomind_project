## Overview 📝

VideoMind is an AI-powered video intelligence platform designed for YouTube videos. Leveraging the Google Gemini and OpenAI APIs, it condenses lengthy content into concise insights, timestamps, and transcripts so you can understand key ideas at a glance.


## Features ✨

- Automatic extraction of key insights and timestamps from YouTube videos.
- Utilizes youtube-transcript-api for getting the transcripts/subtitles YouTube video.
- Option for users to select AI models like *GPT* or *Gemini* for summarization.
- Efficiently summarizes videos, reducing viewing time while preserving essential information.

## Technology Stack

| Layer / Purpose          | Technology |
|--------------------------|------------|
| Frontend landing page    | Next.js 14, React 18 |
| Core UI / workflow       | Streamlit 1.48 |
| Styling                  | Custom CSS, Streamlit theming |
| AI providers             | OpenAI GPT (gpt-4.1, gpt-5), Google Gemini 2.5 |
| Transcripts & timestamps | youtube-transcript-api, Piped captions fallback |
| Env & orchestration      | Python 3.10, Node.js 18+, dotenv |
